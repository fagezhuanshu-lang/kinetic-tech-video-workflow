# 发布与验证范围

公开版 1.1.0，2026-11-18。

## 实际做过的验证

- Windows x64：公开版 runtime 的 bootstrap、doctor、真实模板 plan/prepare/preview、封面导出。
- 公开统一入口：8 秒、480 帧、1920×1080/60fps，自动完成原生渲染、混音、首帧封面、全片解码、最终文件收集。
- 最终 AAC 检查：合成测试音轨三段延迟为 0ms，BGM 残差相关约 0.999959，响度 −17.05 LUFS、真峰值 −7.34 dBTP。样例声音不是自然人声。
- 实际查看公开样例封面与接触表，文字和图形完整。
- 输入存在未知字段时拒绝；重复使用已有输出目录时拒绝，不覆盖旧成果。
- 私人版在真实口播上已有 65 秒端到端验证，且同参数重跑曾复现相同文件。公开版不附该人的视频、字幕、封面或曲目，不将该验证说成公开样例的证明。

另已从不含目标依赖的解释器启动全新虚拟环境，联网安装 Python 依赖、下载锁定 Playwright 并核对 SHA512；新环境 doctor、实际音频运算与原生浏览器预览通过。系统 Node、FFmpeg、Chrome 仍复用已安装程序，这不是空白操作系统的无人值守安装测试。没有 macOS/Linux 全链路或 WorkBuddy 客户端实测。没有对任何底层模型的成功率做统计，不能宣称“弱模型完美运行”。

## 公开版排除项

不包含私有口播、人物封面、全文字幕、未知再分发许可的本地缓存歌曲、账户凭据、本机工程路径、旧工程 UUID 或已有视频输出。演示素材由 `make_demo.py` 现场生成，知识产权范围见根目录第三方声明。

## 构建分享包

`python scripts/package_release.py --out /path/to/new-output-directory` 会生成技能 ZIP、逐文件 SHA256 清单与 ZIP SHA256。它只收集公开项目源文件，排除 git、运行环境、缓存、视频和音轨输出。

下载 GitHub 源码 ZIP 也能获得完整源文件。导入客户端时先检查其技能包格式与执行权限；分享链接不等于自动赋予安装权限。

## 排错

先看 `doctor` 的具体缺项，再看本期输出的 `workflow-state.json` 和 `logs/`。运行失败不能用中间文件代替完成；修复后用新输出目录重跑。当前版本不自动断点续跑。
